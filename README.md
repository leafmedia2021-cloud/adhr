# AHDR website

A responsive, static profile website for Action for Holistic Development and Rights (AHDR), based on the organizational profile provided for Mulago II, Kawempe Division, Kampala.

## Run locally

Open `index.html` in a modern web browser. No build step, package installation, server, or API credentials are required.

The mobile navigation and governance disclosures work in the browser. The email and phone links open the visitor's configured email and calling apps. The site does not collect or store submissions.

## Publish

Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to any static web host, keeping the folder structure intact. For a public deployment, configure the hosting provider to serve HTTPS and use the domain's preferred security settings.

The community photographs are locally bundled and remain available offline. They are illustrative photos from other Ugandan settings, not images of AHDR or Mulago II. Source links and credits are shown beneath each image. The photo by Boango545 is licensed CC BY-SA 4.0; the other two images are CC0. The typefaces load from Google Fonts when an internet connection is available; system sans-serif fonts are used as fallback.
